OSSPlay is a self-hosted object storage and file management platform — bring your own S3-compatible
bucket, get an admin dashboard, per-organization access control, and automated image/video
processing on top of it.

This site covers three kinds of documentation:

- **Getting Started** — install/deploy OSSPlay and get through first-run setup, in order.
- **Guides** — task-oriented how-tos for specific things you're trying to do.
- **Reference** — technical/lookup material: permissions, environment variables, and similar.

If you're setting up a new instance, start with [Initial setup & onboarding](/getting-started/initial-setup).
